# 工程组织、命名与维护

## 命名

| 类型 | 前缀 | 示例 |
|---|---|---|
| 设计令牌 | `color_`, `space_`, `radius_` | `color_surface` |
| 样式 | `style_` | `style_button_primary` |
| 字体 | `font_` | `font_16_regular` |
| 图标 | `icon_` | `icon_settings` |
| 图片 | `img_` | `img_empty_state` |
| 自定义控件 | `wd_` | `wd_touch_target` |
| 页面创建 | `screen_` | `screen_settings_create` |
| 页面动作 | 动词开头 | `screen_settings_reset` |

同类命名保持单复数、时态和单位一致。尺寸变量明确单位，如 `height_px`。

## 纯 C 工程

推荐分层：

```text
ui/
  ui_theme.c/.h          令牌和可复用样式
  ui_components.c/.h     通用组件和组件动作
  screen_*.c/.h          页面结构和业务绑定
  ui_navigation.c/.h     页面切换和共享状态
```

页面不得复制完整视觉样式。页面可以设置几何位置和业务状态，但视觉常量来自主题层。

## XML / LVGL Pro

- XML/Pro 源文件是结构和样式源。
- 可复用样式统一使用 `style_` 前缀。
- 生成文件只构建，不手工编辑。
- 业务回调放在手写 C 模块，避免页面 XML 承担复杂逻辑。
- 定期验证从源文件重新生成的产物与仓库一致。

## 生成代码

- `generated/`、导出工程和工具输出不得手工修改。
- 需要的修改回到生成器源文件或通过受控扩展点实现。
- 生成目录中的临时样式和资源不得被业务代码直接依赖。

## 布局

- 优先使用 `lv_obj_set_flex_flow()`、grid、百分比和 `LV_SIZE_CONTENT`。
- 容器和子元素不要同时锁死同一维度，除非业务确实要求绝对定位。
- 固定尺寸应定义成语义令牌，并记录最小/最大可用空间。
- 页面切换、字体替换或语言切换后重新检查溢出。

## 重构信号

出现以下情况时先整理结构，再继续加页面：

- 三个以上页面重复相同样式；
- 页面同时处理样式、布局、业务和动画；
- 修改一个颜色需要改多个文件；
- 出现无法追踪来源的硬编码尺寸；
- 同类按钮的按下或禁用状态不一致；
- 生成文件被手工修改后重新生成会丢失。
