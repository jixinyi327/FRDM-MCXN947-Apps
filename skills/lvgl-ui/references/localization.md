# LVGL 中英文与本地化

## 单一文案源

- 所有用户可见文本必须通过稳定文本 ID 和统一翻译表获取。
- 页面、组件、菜单、弹窗、状态栏和错误反馈不得各自保存重复的中英文常量。
- 业务页面不要用翻译文本作为状态 ID、对象名或样式名；使用稳定的枚举或标识符。
- 格式化文本必须是完整句式模板，例如 `"x:%d y:%d"`，不要拼接多个翻译片段。
- 占位符在不同语言中允许调整顺序，但参数类型和数量必须一致。
- 翻译表使用静态生命周期存储；不要把临时栈缓冲指针长期交给 LVGL。

推荐结构：

```c
typedef enum {
    UI_TEXT_SETTINGS_TITLE,
    UI_TEXT_SETTINGS_RESET,
    UI_TEXT_SETTINGS_RESET_DETAIL,
    UI_TEXT_COUNT
} ui_text_id_t;

const char *ui_tr(ui_text_id_t id);
```

## 默认语言与切换

- 默认语言必须在产品需求中明确，并在初始化时确定设置。
- 应用不能依赖编译器、终端 locale 或目标 Flash 中的残留值决定默认语言。
- 语言切换入口必须在 UI 中可见，不能只依赖隐藏手势或调试命令。
- 切换后必须同步更新：
  - 页面标题和说明；
  - 菜单、标签、按钮和信息栏；
  - 当前动态状态；
  - 模态框、确认框和错误提示；
  - 与语言绑定的字体样式。
- 对动态状态保留业务数据，切换语言时重新格式化文本，而不是只翻译最后一次字符串结果。
- 同一语言重复设置应保持幂等；非法语言 ID 应拒绝或回退到明确默认值。

## 字体与文字编码

非 ASCII 文案至少同时满足以下条件：

```conf
CONFIG_LV_TXT_ENC_UTF8=y
CONFIG_LV_TXT_ENC_ASCII=n
```

如果生成字体使用压缩字形（常见为 `bitmap_format = 1`）：

```conf
CONFIG_LV_USE_FONT_COMPRESSED=y
```

缺少 UTF-8 时常见症状是中文方框；UTF-8 正确但缺少压缩字形解码时常见症状是
中文全部空白。看到这两种症状时，先核对配置，不要先重做翻译或布局。

## 字体子集

- CJK 字库按实际翻译表生成子集，避免把完整字库打入小 Flash。
- 同时生成所有 UI 字号，例如正文 16 px 和标题 24 px。
- 子集必须包含 ASCII 中的数字、符号和格式化字符。
- 文案修改后重新生成字体，并把生成命令保存为项目脚本。
- 生成后自动检查翻译表非 ASCII 字符在字体 C 文件中的覆盖率。
- 字体生成参数必须记录：字号、bpp、压缩、预过滤、字形范围、变量名和源字体版本。
- 如果运行时不支持 fallback，不要假设“缺字会自动从系统字体补齐”。

## 布局与可读性

- 两种语言都必须在真实字号下检查换行、截断和控件对齐。
- 不要根据某一种语言的字符数锁死容器宽度。
- 双行状态栏必须分别验证两行内容不重叠、不截断。
- 语言切换按钮应显示下一步动作或当前可选语言，并保持文案语义明确。
- 图标、徽标或缩写若保留英文，必须确认它在两种语言下仍有意义。

## 验收矩阵

| 测试 | 通过条件 |
|---|---|
| 冷启动 | 按需求进入明确默认语言 |
| 中文完整性 | 无方框、空白、乱码或缺字 |
| 英文完整性 | 无中文残留和字符截断 |
| 双向切换 | 静态和动态文案全部立即更新 |
| 动态状态 | 坐标、覆盖率、误差、设置反馈不丢失 |
| 模态框 | 标题、正文、按钮同步切换 |
| 字体 | 两种语言使用对应字体且无布局跳动 |
| 重启 | 默认语言行为可复现 |
