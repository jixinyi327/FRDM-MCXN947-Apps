# 交互、焦点与容错

## 触控命中

- 手指目标建议至少 `38x38 px`，约 9 mm。
- 触控笔目标建议至少 `21x21 px`，约 5 mm。
- 图标可见尺寸小于目标尺寸时，使用：

```c
lv_obj_set_ext_click_area(button, 8);
```

扩展区域不能与其他可点击目标重叠。圆角、透明背景和视觉留白必须与真实命中区
一致或更小。

## 即时反馈

- 按下状态：颜色、边框、位移或缩放，至少一种可见变化。
- 执行状态：禁用重复触发，显示忙碌或进度。
- 完成状态：明确说明成功、失败、未改变或新增数据。
- 错误状态：说明原因，并保留重试或返回路径。

反馈动画应短、局部、可中断。错误颜色恢复后必须回到规定的正常状态。

## 破坏性操作

删除、重置、恢复出厂和覆盖配置需要：

1. 明确说明影响范围；
2. 主按钮使用危险语义；
3. 提供取消或返回；
4. 完成后显示结果。

单页测试工具如果业务明确允许快速重置，也必须在视觉和文案上说明“重置当前页面”。

## D-pad 与编码器

- 为每类输入设备建立 `lv_group_t`。
- 只把真正可操作的控件加入焦点组。
- 明确首个焦点和页面返回焦点。
- 使用 `lv_group_set_default()`、`lv_group_focus_obj()` 和
  `lv_group_focus_next/prev()` 管理导航。
- 自定义控件应处理 `LV_EVENT_FOCUSED`、`LV_EVENT_DEFOCUSED`、
  `LV_EVENT_KEY`、`LV_EVENT_PRESSED` 和 `LV_EVENT_RELEASED`。
- `LV_KEY_ENTER` 必须同时产生即时视觉反馈和业务动作。
- 禁用控件要从焦点组移除或跳过，不能只做灰色外观。
- 模态层出现时保存原焦点，关闭后恢复到合理控件。

## 恢复路径

| 情况 | 用户应能做什么 |
|---|---|
| 点错按钮 | 取消或返回 |
| 参数无效 | 修正后重试 |
| 操作失败 | 看到原因并重试 |
| 操作中离开 | 安全取消或明确后台继续 |
| 模态框关闭 | 回到触发它的控件 |
| 误触破坏性操作 | 在确认前取消 |
