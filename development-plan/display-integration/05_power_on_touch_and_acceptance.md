# 点亮、触摸与验收流程

## 1. 准备

- FRDM-MCXN947；
- LCD-PAR-S035；
- 已装配的 MCU-Link/J17 调试链路；
- 限流 USB 电源或可调电源；
- 万用表；
- 示波器/逻辑分析仪；
- 当前已编译的 LVGL 工程。

## 2. 组装前检查

- 检查屏幕、FPC、转接板连接器是否破损；
- 检查转接板 SW1；
- 检查 J1/J5/J3/J6 的选择；
- 检查背光电阻和 DC-DC 区域无短路；
- 确认 FPC 方向；
- 确认屏幕不会压到 FRDM 上的元件。

## 3. 上电顺序

1. 不接屏幕，先验证 FRDM 可烧录、串口正常。
2. 断电。
3. 连接屏幕转接板。
4. 只接 J17 供电/调试。
5. 用万用表确认 3.3 V。
6. 观察背光是否点亮。
7. 烧录 LVGL 示例。

若背光不亮，先检查背光控制、SW1 和电源；不要反复烧录。

## 4. 编译和烧录

```bash
source development-plan/scripts/env.sh
cd "$MCXN_SDK"

west build -b frdmmcxn947 \
  mcuxsdk/examples/lvgl_examples/lvgl_guider_bm \
  -d build/lvgl_s035_core0 -p always \
  --config debug -Dcore_id=cm33_core0

west flash -d build/lvgl_s035_core0 -r linkserver
```

当前本机已完成编译，烧录需连接 USB 后执行。

## 5. 首次显示验收

检查：

- 背光亮；
- 全屏无黑边/偏移；
- 方向正确；
- 红、绿、蓝顺序正确；
- 白色和黑色正常；
- 渐变无明显异常色带；
- 文字边缘无明显撕裂；
- 触摸坐标与显示位置一致。

### 常见画面判断

| 现象 | 优先检查 |
|---|---|
| 背光正常但全黑 | RST、D/C、CS、WR、SW1、初始化序列 |
| 全白 | 显示初始化/偏置/复位失败 |
| 画面对角线错位 | 数据总线位序或分辨率 |
| 颜色互换 | RGB/BGR、invert、RGB565 字节序 |
| 画面上下翻转 | MADCTL/orientation |
| 触摸位置镜像 | GT911 X/Y 交换/反向 |
| 局部闪烁 | 缓冲/tearing/TE 或电源纹波 |

## 6. 显示总线检查

逻辑分析仪建议抓：

- RESET；
- CS；
- D/C；
- WR；
- D0–D15；
- TE（可选）。

确认：

- CS 只在有效期拉低；
- D/C 在命令和数据阶段正确；
- WR 边沿不过冲；
- 数据建立/保持满足时序；
- 复位时序满足面板规格；
- 连续写像素时无丢帧/断流。

## 7. 触摸验收

### 基础测试

- 单点按下/抬起；
- 5 点坐标；
- 边缘和四角；
- 快速滑动；
- 长按；
- 同时触摸；
- 手指离开后坐标释放。

### 坐标测试

在 UI 上画十字或九宫格，按下屏幕对应位置，检查：

- 左上、右上、左下、右下；
- 中心；
- X/Y 是否交换；
- X 或 Y 是否镜像；
- 边缘是否有偏移；
- 显示缩放和触摸缩放是否一致。

### GT911 调试

- I2C 时钟先 100 kHz；
- 扫描 `0x5D` 和 `0x14`；
- 观察 INT 是否下降；
- 检查 RESET 是否由 LCD 初始化统一控制；
- 检查 INT 上拉/下拉和中断边沿；
- 读寄存器确认点数、坐标和触摸 ID。

## 8. 性能基线

记录：

- 全屏清屏时间；
- 单色块刷新时间；
- 文本滚动帧率；
- 页面切换时间；
- CPU 占用；
- SmartDMA/EDMA 完成时间；
- LVGL heap 最低水位；
- 最大局部缓冲；
- 背光电流；
- 3.3 V 纹波。

建议分别测试：

1. 纯 LVGL 静态 UI；
2. 带动画 UI；
3. 触摸持续触发；
4. 网络并发；
5. 摄像头/AI 并发；
6. 4 小时/24 小时压力。

## 9. 电源与热

- 测 3.3 V 启动峰值；
- 测满白背光电流；
- 测调光最小/最大；
- 测 DCDC 和 LDO 温升；
- 测屏幕 FPC 附近温度；
- 测 FRDM 与转接板叠层是否影响散热；
- 测高温 70 °C 附近亮度和触摸是否正常；
- 产品目标温度超过 70 °C 时必须换屏。

## 10. 稳定性验收

- 连续显示 24 小时无花屏；
- 触摸 10,000 次无丢点；
- 1000 次插拔/复位无死机；
- 网络/电机等噪声负载下无触摸跳点；
- 断电重启后屏幕和触摸自动恢复；
- 升级固件后屏幕配置仍正确；
- 背光开关不引起 MCU 复位。
