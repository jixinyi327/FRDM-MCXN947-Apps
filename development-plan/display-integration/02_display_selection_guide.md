# 屏幕选型决策指南

## 1. 先选“控制器”，再选“面板”

屏幕不是只有尺寸和分辨率。对 MCU 产品，真正决定软件和硬件工作量的是：

```text
面板玻璃 + 显示控制器 + 触摸控制器 + 背光/电源 + 连接器 + 驱动支持
```

同分辨率的两块屏，控制器不同，驱动、初始化序列、显存、刷新方式和采购风险都可能完全不同。

## 2. MCXN947 的能力边界

| 屏幕类型 | MCXN947 适配性 | 说明 |
|---|---|---|
| 8080 8/16 位并口 + 内置显存控制器 | 最推荐 | FlexIO + SmartDMA，LCD-PAR-S035 已验证到编译级 |
| SPI 显示控制器 | 可行 | 适合小屏、低刷新率和局部刷新；全屏吞吐低 |
| 带显存的 QSPI/SPI 智能屏 | 可行 | 主控只需发送绘图命令，但成本和供应链需评估 |
| RGB 并口裸屏 | 不推荐直接驱动 | MCXN947 没有像 i.MX RT 那样的专用 LCDIF；需要外部控制器 |
| MIPI DSI | 不支持直接连接 | 需要桥接芯片 |
| LVDS/eDP/HDMI | 不支持直接连接 | 需要转换器或换平台 |
| Linux 大屏方案 | 不匹配 | MCXN947 是 MCU，不是应用处理器 |

## 3. 接口选择

### 8080 并口

优点：

- 带宽高；
- 适合 320×480 及以上；
- 可使用 8 或 16 位数据；
- FlexIO 可编程；
- SmartDMA 可减轻 CPU。

代价：

- 占用数据线和控制线多；
- PCB 走线多；
- 需要正确的 WR/RD/CS/D/C 时序；
- 对连接器机械稳定性要求高。

### SPI

优点：

- 线少；
- 易跨板；
- 适合 1.8–3.5 英寸低帧率 UI。

代价：

- 全屏刷新慢；
- 16 位像素需要两个字节；
- CS/DC 和 DMA 时序增加开销；
- 大屏不适合。

### 外置显示控制器

适合：

- 主控引脚少；
- 需要智能屏；
- 需要视频/大分辨率；
- 希望更换 MCU 时保留屏幕。

代价：

- 命令集和固件生态可能锁定供应商；
- 部分功能无法精细控制；
- 成本和生命周期需要确认。

## 4. 分辨率和全屏带宽

RGB565 每像素 2 B：

```text
单帧字节 = 宽 × 高 × 2
每秒字节 = 单帧字节 × FPS
```

| 尺寸/分辨率 | 单帧 | 30 FPS | 60 FPS |
|---|---:|---:|---:|
| 320×240 | 150 KiB | 4.5 MiB/s | 9.0 MiB/s |
| 480×320 | 300 KiB | 9.0 MiB/s | 18.0 MiB/s |
| 800×480 | 750 KiB | 22.5 MiB/s | 45.0 MiB/s |
| 1024×600 | 1171 KiB | 35.2 MiB/s | 70.3 MiB/s |

这里是有效像素带宽，实际还要加命令、空周期、DMA、LCD 控制器刷新和 UI 重绘开销。

SPI 30 MHz、8-bit 理论原始带宽约 3.75 MB/s。480×320 RGB565 全屏约 307,200 B，即使忽略命令开销，理想上限约 12 FPS。产品若要求流畅全屏动画，应使用并口或智能屏。

## 5. 内存预算

MCXN947 总 SRAM 512 KB，还要容纳：

- 应用和 RTOS；
- 网络/TLS；
- 摄像头/音频；
- DMA；
- LVGL heap；
- LVGL draw buffer；
- 屏幕帧缓冲。

### 常见配置

| 配置 | 缓冲区占用 |
|---|---:|
| 480×320 单整帧 RGB565 | 307,200 B |
| 480×320 双整帧 | 614,400 B，超出可用 SRAM |
| 480×320 两个 1/10 屏高局部缓冲 | 61,440 B |
| 800×480 单整帧 | 768,000 B，超出 SRAM |
| 480×320 单 1/10 局部缓冲 | 30,720 B |

对 MCXN947，推荐：

- `LV_DISPLAY_RENDER_MODE_PARTIAL`；
- 1/10 至 1/5 屏高的局部缓冲；
- 双缓冲仅在内存允许时启用；
- 图片和字体尽量放外部 Flash；
- 不在 UI 与摄像头/NPU 同时运行时使用整帧双缓存。

## 6. 触摸选型

| 触摸类型 | 优点 | 风险 |
|---|---|---|
| GT911 I2C | 成熟、多点、MCUXpresso 支持 | 地址/复位时序、共用 reset、EMI |
| I2C 单点触摸 | 简单、成本低 | 手势和多点能力弱 |
| SPI 电阻触摸 | 成本低、可戴手套 | 多点差、校准、透光与磨损 |
| 红外触摸框 | 大尺寸、可选厚盖板 | 边框大、成本高 |
| 无触摸 | 最简单 | 产品交互受限 |

工业产品必须明确：

- 是否要求湿手/手套；
- 是否要求厚盖板；
- 是否要求抗水膜误触；
- 是否需要 5 点以上；
- 触摸是否必须在 MCU 休眠时唤醒。

LCD-PAR-S035 的 GT911 适合普通 HMI，但湿手、强干扰和厚盖板能力需实测。

## 7. 环境与光学

### 工作温度

LCD-PAR-S035 为 `-20~70 °C`，不满足许多工业 `-40~85 °C` 或更高要求。宽温产品应选：

- 宽温 TFT/IPS 面板；
- 宽温触摸控制器；
- 宽温背光；
- 重新验证 FPC、胶黏剂和偏光片。

### 亮度

| 场景 | 建议 |
|---|---|
| 室内普通设备 | 250–500 cd/m² 可评估 |
| 强室内光/半户外 | 500–800 cd/m² |
| 阳光直射 | 800–1000+ cd/m²，并考虑防眩/半反半透 |

高亮度会显著增加背光电流和热负荷。

### 色域与可读性

- 医疗、工业仪表需评估色偏；
- 户外需要防眩、抗反射和宽视角；
- RGB565 已能覆盖多数 MCU HMI，但渐变更容易有色带；
- 需要更高色深时选择 RGB666/RGB888 控制器，并核算带宽。

## 8. 机械和连接器

必须确认：

- 外形尺寸和可视区；
- 安装孔/定位柱；
- FPC 长度、弯折半径和插拔方向；
- FPC 触点在上/下；
- 32-pin LCD + 8-pin touch 是否为同一 FPC；
- 连接器生命周期和锁扣；
- 屏幕厚度、盖板和胶层；
- 运输/振动下的 FPC 受力；
- 维修可拆卸性。

LCD-PAR-S035 使用独立 LCD FPC 和触摸 FPC，转接板再接到 FRDM。量产产品通常会去掉转接板，把连接器直接放到产品主板上。

## 9. 电源和背光

选屏时必须确认：

- 逻辑电压是 1.8 V 还是 3.3 V；
- 显示模拟电源是否需要 2.8–3.3 V；
- 背光是串联还是并联；
- 背光正向电压和最大电流；
- 是否需要恒流驱动或升压；
- 背光是否能 PWM 调光；
- 关断时是否完全断电；
- 面板上电时序；
- 背光浪涌和 EMI。

LCD-PAR-S035 的背光是典型 3.1 V、120 mA，适合低压并联方案；更大屏通常需要恒流升压，不能直接接 3.3 V。

## 10. 软件生态评分

| 项目 | 必须确认 |
|---|---|
| 控制器型号 | 不能只写“兼容 ST7789/ST7796” |
| 初始化序列 | 是否针对当前玻璃和批次调过 |
| NXP SDK 支持 | 是否有 ST7796/ILI/GT911/FT5x 等驱动 |
| LVGL 支持 | 是否有 flush、touch、orientation 适配 |
| Zephyr 支持 | shield/DTS 是否覆盖目标板 |
| 工具链 | 能否在 GCC 14.2.x 下构建 |
| GUI 工具 | GUI Guider、SquareLine 或其他 |
| 字体/图片 | Flash/RAM 和压缩方案 |

## 11. 供应和生命周期

除技术参数外，必须做：

- 原厂和代理双渠道；
- 面板/触摸 FPC 的版本变更通知；
- 批次亮度、色偏、触摸灵敏度差异；
- MOQ；
- 停产/EOL 风险；
- 替代控制器和替代玻璃方案；
- 量产前冻结具体供应商料号。

HP35001-DCT 规格年代较早，尤其不能把“NXP 开发板在售”直接等同于“该面板可长期稳定供货”。

## 12. 推荐决策流程

1. 写清产品尺寸、环境和触摸需求。
2. 确定整帧内存和帧率。
3. 选控制器和接口。
4. 核对接线、电源、背光和 FPC。
5. 验证 SDK/LVGL/Zephyr 支持。
6. 采购 3–5 块样屏做批次验证。
7. 做亮度、颜色、触摸、EMC、振动和温升测试。
8. 冻结料号、初始化序列和 UI 配置。
9. 固化生产测试和替换料方案。

## 13. 按产品的建议

| 产品 | 推荐屏幕 |
|---|---|
| FRDM 学习/原型 | LCD-PAR-S035，J8 并口 |
| 小型家电面板 | 2.4–3.5 英寸 SPI/8080，RGB565，单点/多点触摸 |
| 工业 HMI | 3.5–5 英寸宽温 8080/智能屏，500+ cd/m² |
| 户外设备 | 800+ cd/m²，宽温，防眩；重新评估整机热设计 |
| 医疗设备 | 关注色准、长期稳定、清洁剂和认证，不只看分辨率 |
| 视觉+显示一体 | 优先小屏/局部刷新，避免与摄像头争用 SRAM |
| 大屏 Linux 产品 | 不使用 MCXN947，选择应用处理器 |
