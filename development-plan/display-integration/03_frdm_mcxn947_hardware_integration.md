# FRDM-MCXN947 硬件适配

## 1. 首选连接方式

LCD-PAR-S035 应优先通过 J1 接 FRDM-MCXN947 的 J8 FlexIO/LCD 接口，采用 16 位 8080 模式。

原因：

- FRDM 有专用 28-pin FlexIO/LCD 连接器；
- MCUXpresso 当前 LVGL 适配就是 16 位 8080；
- SmartDMA 可搬运像素；
- 比 Pmod SPI 有更高全屏吞吐；
- 软件和引脚映射已经过编译验证。

## 3. J8 直连检查

1. 断电。
2. 将 LCD-PAR-S035 的 J1 与 FRDM J8 对齐。
3. 核对 Pin 1 标记和板卡方向；原理图注明“SMD to B side”。
4. 确认 SW1 为 16 位 8080。
5. 检查连接器是否完全插入，避免偏一针。
6. 用万用表检查 3.3 V 与 GND 无短路。
7. 第一次上电使用 USB 限流或可调限流电源。

## 4. 电源选择

FRDM J8 已提供 3.3 V。优先由 FRDM 给屏幕转接板供电，避免额外 5 V。

需要确认：

- 转接板 J1 的 3.3 V 路径是否已启用；
- M3406 DC-DC 输出是否通过 0 Ω/跳线接到 VDD；
- J1 3.3 V 是否与 DC-DC 输出短接；
- USB J3 是否接入；
- J6 2×2 电源跳线状态；
- 是否存在 5 V 反灌 3.3 V 的路径。

建议先断开独立 USB/J6，仅接 FRDM J8 和 MCU-Link，测量 VCC/VDD 后，再决定是否使用 DC-DC。

## 5. 电流预算

仅屏幕模块建议预留至少：

```text
3.3 V 显示 + 触摸 + 背光：约 150 mA 典型
设计裕量：至少 200 mA
```

还需加：

- 3.3 V 主 LDO 的余量；
- 其他扩展板；
- 无线模块瞬时电流；
- 背光调光和满白画面；
- 线缆压降。

如果同时接 Ethernet、USB Host、摄像头等，必须重新做整板功率预算。

## 6. 背光控制

原理图使用 Q1 控制背光，GPIO 经 R1 到栅极，R14 为默认偏置，R3 限流。

- 背光典型 3.1 V/120 mA；
- 不要直接把 LED_A 接 5 V；
- PWM 调光频率应避开摄像头帧率、音频和触摸扫描；
- 低亮度时检查是否存在闪烁和噪声；
- 关屏时关闭背光，降低功耗；
- 若需要更高亮度，换恒流升压驱动，不能简单减小 R3 无限增流。

## 7. SPI 备选方案

SPI 模式通过转接板 Pmod J5 连接。FRDM-MCXN947 的 J7 Pmod 默认 DNP，因此需要：

1. 装配 J7；
2. 使用正确的 Pmod 线；
3. SW1 设置到 4-wire SPI；
4. 引脚连接显示 CS、SCLK/WR、MOSI、D/C、RST；
5. 连接触摸 SCL/SDA/INT；
6. 软件配置为半双工写或正确处理 MISO；
7. 从较低时钟开始验证。

注意：

- 当前 FRDM-MCXN947 的默认 LVGL 示例使用 FlexIO 8080，不使用 SPI；
- SDK 中存在 `flexcomm_spi_lcd_par_s035` 支持代码，但它不是当前已验证的默认板级路径；
- Pmod J5 未提供并行数据总线和所有控制信号；
- 全屏刷新速度会显著下降；
- J7 默认 DNP，且与摄像头/Pmod/PDM/Arduino 网络有共享。

## 8. SW1 接口档位

| 模式 | IM2:IM0 | 适用连接 |
|---|---|---|
| 16-bit 8080 | 010 | J1 -> FRDM J8，推荐 |
| 8-bit 8080 | 011 | 低速/少数据线，需改软件 |
| 3-wire 9-bit SPI | 101 | 特定 SPI 控制器 |
| 4-wire 8-bit SPI | 111 | Pmod SPI |

实板上应以丝印/开关位置和 IM 引脚电平双重确认。只改软件而不改 SW1 是常见黑屏原因。

## 9. 共享资源

### Arduino/电机网络

J8 的 P4_12、P4_13、P4_16、P4_17、P4_20、P4_21 等引脚与 Arduino、电机电流采样或 USB 控制相关。使用显示时应：

- 不把这些网络同时用于模拟采样；
- 核对 0 Ω/焊桥选择；
- 检查电机板是否占用相同引脚；
- 避免在运行时把同一引脚切回 GPIO。

### Pmod/摄像头

SPI 备选路径中的 P0_4/P0_5/P3_2/P3_3 与摄像头/Pmod 相关，使用前必须形成接口并发矩阵。

### 串口

LCD 触摸 I2C 使用 P4_0/P4_1；不要把调试 UART 的 P1_8/P1_9 错误复用为触摸 I2C。

## 10. 自定义板如何画

量产产品不建议照搬转接板，建议：

- 直接把 32-pin LCD FPC 和 8-pin 触摸 FPC 放产品板；
- 或选择集成触摸的单一 FPC；
- 若主控到屏幕距离短，可用 8080；
- 若距离长，评估串行智能屏或降低速率；
- 背光恒流/升压靠近屏幕；
- FPC 连接器加机械固定；
- 所有数据/控制线远离 DCDC 和天线；
- 触摸 I2C 上拉只保留一组；
- 背光 PWM 回路控制面积；
- 预留背光电流、3.3 V、复位和触摸中断测试点。

## 11. 最小硬件验收

- [ ] 3.3 V 正常，无过冲和反灌。
- [ ] SW1 与软件模式一致。
- [ ] 背光可关断，电流在预算内。
- [ ] 复位由 GPIO 控制且默认安全。
- [ ] D/C、CS、WR 和数据线无短路/串扰。
- [ ] I2C 上拉和总线电平正确。
- [ ] 触摸 INT 可被 MCU 捕获。
- [ ] FPC 方向、触点和机械锁紧正确。
- [ ] 屏幕不遮挡天线、按键或散热。
