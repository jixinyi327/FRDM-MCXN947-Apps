# Touchscreen Tester

FRDM-MCXN947 + LCD-PAR-S035 的触摸屏测试工程。应用位于主 Git 仓库，
显示与触摸驱动继续使用 `firmware/patches/` 中已验证、可复现的 SDK 改动。

## 页面

| 页面 | 功能 |
|---|---|
| Free Draw | 404x164 单色画布，连续绘制并检查轨迹连续性 |
| Block Check | 12x7 检测网格，填充每个可达区域并统计覆盖率 |
| Touch Accuracy | 移动靶点，统计误差和次数；未命中时抖动并闪红 |
| Settings | 绘制线宽、触摸坐标显示、测试数据重置 |

底部操作区固定为左侧 `Reset`、中间信息输出栏、右侧矩形 `TAB` 按钮。
两个按钮均为 `72x48`。Reset 根据当前页面清除对应测试数据，中间信息栏高度同为
48 px，分两行显示当前状态和详细数据，例如坐标与线宽、覆盖率、精度统计或设置结果。
Reset 会先打开确认面板，用户可取消或确认，避免误触清空测试数据。

右侧 `TAB` 按钮打开纵向标签列表。选择标签后，菜单向按钮方向收回，
页面按索引方向滑入：进入后面的页面时从右侧进入，返回前面的页面时从左侧进入。
点击菜单外部会原路收回。

精度测试以靶点可见外圈作为命中范围。命中后靶点平滑移动到下一个位置；
未命中时靶点保持在原位，信息栏显示 `MISS` 和偏差，准星短暂抖动并从青色
闪成红色，再恢复青色，便于用户立即重试。

## 中英文切换

应用默认以中文启动。设置页提供语言按钮：中文界面显示 `English`，英文界面显示
`中文`。切换后会同步更新页面标题、菜单、按钮、状态栏、精度反馈和重置确认面板，
并根据当前语言切换 Montserrat 与 Source Han Sans 中文子集字体。

工程固定启用 `CONFIG_LV_TXT_ENC_UTF8=y`。中文源码必须保持 UTF-8 编码并禁用
`LV_TXT_ENC_ASCII`，否则 LVGL 会把中文 UTF-8 字节当作缺字方框。

翻译文本集中在 `ui_i18n.c`。修改中文文案后运行：

```bash
./apps/touchscreen_tester/scripts/generate_fonts.sh
```

该脚本只打包翻译表实际使用的中文字符，不引入完整 1.2 MB CJK 字库。

## 交互和性能约束

- 所有页面只由 `cm33_core0` 创建和绘制；
- LCD/GT911 只由一个核访问；
- LVGL 使用两块 480x80 RGB565 局部缓冲；
- VBlank TE 每次完整 LVGL 更新只等待一次；
- SmartDMA 完成后释放当前 LVGL 缓冲；
- UI 处理节拍固定为 16 ms；
- 页面切换只平移 14 px，避免大范围透明合成；
- 自由绘制只失效当前线段覆盖的矩形，不刷新整块画布。
- 颜色、字体和组件状态集中在 `ui_theme.c/.h`；
- pressed/focused/disabled/checked 通过命名样式和 `LV_STATE_*` 表达；
- 设置页的小尺寸线宽按钮和坐标开关使用 `lv_obj_set_ext_click_area()`。

UI 视觉元素目前使用基础主题。颜色、字体和组件风格应由后续独立 UI 风格 Skill
统一约束，性能行为继续由 `$frdm-mcxn947-lvgl-ui-performance` 约束。

## 构建

```bash
./apps/touchscreen_tester/build.sh
```

烧录到当前连接的 FRDM-MCXN947：

```bash
./apps/touchscreen_tester/build.sh --flash
```

构建后会运行 UI 配置审计。当前预期静态 RAM 约 273 KiB，Flash 约 424 KiB。

## 实机验收

1. 底部 Reset、双行信息栏和矩形 TAB 对齐，两个按钮均为 72x48；
2. 静止页面保持 60 秒，无闪烁、花屏或复位；
3. 慢速拖动黑色轨迹，线条连续且无明显撕裂；
4. 快速拖动，允许 ST7796 单 GRAM 带来的极短暂撕裂，但不能持续异常；
5. 连续绘制 2 分钟，界面不逐渐卡顿；
6. 打开和关闭标签菜单，确认关闭路径回到矩形 TAB；
7. 在标签间往返切换，确认正向向右进入、返回向左进入；
8. 点击菜单外区域，确认菜单收回且不会误切换页面；
9. 检查信息栏两行内容是否随坐标、网格覆盖、精度统计和设置项实时更新且不被截断；
10. 分别在各页面点击 Reset，确认只重置当前页面；设置页 Reset 清除全部测试数据。
11. 在精度页点击靶点外，确认出现 `MISS`、准星抖动并闪红后恢复，且靶点不移动；
12. 随后正确点击靶点，确认反馈恢复且靶点平滑移动到下一个随机位置。
13. 点击 Reset 时先确认出现取消/确认面板，取消和点击面板外部均不修改数据。
14. 默认启动为中文，检查所有页面和状态信息无缺字或截断。
15. 在设置页切换英文，再切回中文，确认字体、菜单、状态栏和确认弹窗同步切换。
