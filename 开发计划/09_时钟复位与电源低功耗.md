# 时钟、复位与电源低功耗

## 1. 时钟树

MCXN947 的主要时钟资源：

- 144 MHz FRO；
- 12 MHz FRO；
- 16 kHz FRO；
- 最高 50 MHz 的低功耗晶振接口；
- 32.768 kHz RTC 晶振；
- 2 个 PLL；
- 多路分频、门控和时钟监测。

FRDM 板提供：

| 时钟 | 频率 | 用途 |
|---|---:|---|
| Y1 | 24 MHz | MCU 高精度系统参考 |
| Y2 | 32.768 kHz | RTC/低功耗 |
| Y3 | 50 MHz | LAN8741 RMII PHY |
| Y4 | 16 MHz | MCU-Link LPC55S69 |

开发时不要只修改 CPU 频率，必须同时检查：

- AHB/IP 总线上限；
- Flash 等待周期；
- 外设功能时钟；
- ADC/PWM/通信的定时基准；
- USB/Ethernet PHY 时钟；
- 低功耗模式允许的时钟源。

## 2. 时钟初始化策略

SDK 示例通常通过 `BOARD_InitBootClocks()` 进入预置的 150 MHz 配置。自定义产品建议：

1. 以 MCUXpresso Config Tools 的时钟图生成配置；
2. 把配置纳入版本管理，不依赖图形工具缓存；
3. 定义每个外设的目标时钟和容差；
4. 上电后测量实际时钟输出；
5. 在高低温、USB/Ethernet 活动、PLL 锁定和低功耗切换时复测。

测试顺序：

1. 先用内部 FRO 启动；
2. 再验证外部 24 MHz；
3. 锁定 PLL；
4. 切换系统时钟；
5. 最后启用 USB/Ethernet 等对时钟敏感的模块。

## 3. 复位体系

需要区分：

- POR 上电复位；
- 外部复位 `RESET_B`；
- 看门狗复位；
- 软件系统复位；
- 核心单独复位；
- 外设单模块复位；
- 调试/安全生命周期导致的复位或拒绝访问。

板载 SW1 拉低复位，D1 指示复位。自定义板应保留：

- 可访问的复位测试点；
- 调试器可控的复位网络；
- 明确的复位源读取和日志；
- 外部看门狗/电源监控接口预留。

不要用 GPIO 直接驱动一个强上拉的复位网络而不评估电流和毛刺。

## 4. 电源域

MCXN947 的电源域不是简单的“一颗 3.3 V”：

- VDD_SYS：系统 LDO、检测、时钟等；
- VDD_CORE：DCDC 或 LDO_CORE 输出；
- VDD、VDD_P2/P3/P4：IO 电源；
- VDD_ANA：模拟电源；
- VDD_BAT：VBAT/AON 和 Port 5；
- VDD_USB：USB PHY 模拟电源；
- VUSB1_VBUS：USB VBUS 检测/供电输入。

硬性规则：

- VDD_P4 和 VDD_ANA 应同压，允许偏差仅约 ±0.1 V；
- VDD_BAT 必须在 VDD_SYS 之前或同时上电；
- VDD_CORE 在 VDD 之后上升；
- 若不与 VDD 同接，VDD_P2/P3/P4 必须在 VDD_SYS 之后上升；
- VDD_USB 的工作范围为 3.0 至 3.6 V，不能把它当普通 1.8 V IO；
- USB HS 在 VDD_CORE 低于 1.1 V 时不支持。

FRDM 默认由 P3V3 经电阻/J24 形成 `P3V3_MCU`，再分配给各 MCU 电源域。DCDC_CORE 默认启用，L2 为约 1.5 µH 的 DCDC 电感。

## 5. DCDC 与 LDO 选择

开发板默认 DCDC_CORE 模式，适合性能与功耗；也可通过板上 0 Ω 配置切到 LDO_CORE。自定义板必须根据数据手册重新核算：

- 输入电压和输出目标；
- 电感饱和电流、DCR、尺寸和布局；
- 输入/输出电容的有效值、ESR 和偏压降额；
- 纹波、瞬态和效率；
- DCDC_LX 回流面积；
- 轻载与深度低功耗时的状态；
- 失效模式。

不能只复制开发板电感型号而不核算负载和温度。

## 6. 低功耗模式

常见状态和典型特性：

| 状态 | 典型保留/能力 | 典型唤醒 |
|---|---|---|
| Sleep | 外设可继续运行 | 很快 |
| Deep Sleep | 完整 RAM 可保留，约 170 µA 级 | 约 8.7 µs |
| Power Down | 完整 RAM 可保留，约 5.2 µA 级 | 约 9.8 µs |
| Deep Power Down | RTC、32 KB RAM、复位等保留，约 2 µA 级 | 约 5.3 ms |
| VBAT | 最多 4 × 8 KB ECC RAM，可关断主域 | 依赖唤醒源 |

典型值不是系统指标。系统总功耗还包括：

- MCU IO 漏电和上拉；
- 外部 QSPI Flash；
- Ethernet PHY；
- CAN 收发器；
- USB CC/PD 逻辑；
- LDO 静态电流；
- 传感器和显示背光。

## 7. 低功耗设计流程

1. 列出所有必须保持的状态和唤醒源。
2. 为每个外设决定“运行、门控、断电、保留”策略。
3. 设计外部电源开关和上拉策略，避免通过 IO 反灌。
4. 编写进入/退出流程，保存并恢复上下文。
5. 用电流探头测各阶段波形和电荷。
6. 做 USB、Ethernet、CAN、调试器连接/断开组合测试。
7. 做高温、低温、低电压和电池临界点测试。

## 8. 板载电流测量注意

板级手册的电源网络提供插入电流表/跳线的能力，但默认连接和 DNP 状态必须按原理图确认。测量时注意：

- 不要误断调试器或 3.3 V 主供；
- 测 VDD_CORE 需使用合适带宽和低插入阻抗；
- DCDC 开关纹波会影响平均值；
- 低功耗 µA 测量需要消除仪表和探头负载；
- 探针地线要短，避免把噪声注入 MCU。

## 9. 建议实验

| 实验 | 验收 |
|---|---|
| 24 MHz/PLL 切换 | 中断、UART、PWM 频率不漂移 |
| Sleep/Deep Sleep 往返 | 上下文完整、电流符合预算 |
| RTC 唤醒 | 时间准确，掉电域状态正确 |
| Deep Power Down | 唤醒时间、RAM 保留范围符合设计 |
| 看门狗复位 | 可识别复位源并恢复业务 |
| 低电压边界 | HVD/LVD 不误触发，数据不损坏 |
| 外部 Flash 断电 | 无 IO 反灌和异常漏电 |

## 10. 常见错误

- 只给 VDD 供电，漏接 VDD_ANA/VDD_BAT/VDD_USB。
- VDD_P4 与 VDD_ANA 不同压。
- 把 VDD_CORE 直接接 3.3 V。
- DCDC 电感离芯片远、回路大。
- 低功耗前未关闭调试器、PHY 或显示背光。
- 通过未断电 GPIO 给目标外设反向供电。
- 未保留低功耗阶段测试点，导致无法定位漏电来源。
