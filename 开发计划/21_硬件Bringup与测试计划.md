# 硬件 Bring-up 与测试计划

## 1. 首件检查

上电前：

- [ ] 核对 BOM、DNP 和装配方向。
- [ ] 目视/显微检查 BGA、焊桥、连锡和偏位。
- [ ] 用万用表查各电源轨对地阻抗。
- [ ] 查 VDD_ANA/VDD_P4 是否短接且无错压。
- [ ] 查 1.2 V 级 VDD_CORE 不得接 3.3 V。
- [ ] 查复位、BOOT、SWD、UART 默认状态。
- [ ] 查 DCDC_LX 无短地。
- [ ] 查外部 PHY/Flash/收发器电源是否独立可控。
- [ ] 确认首件使用限流电源。

## 2. 上电顺序测试

最好使用多通道示波器同时观察：

- VBAT；
- VDD_SYS；
- VDD_CORE；
- VDD IO 域；
- VDD_ANA；
- VDD_USB；
- RESET_B；
- 调试口/时钟。

检查：

- 顺序符合芯片要求；
- 没有反向供电/闩锁；
- VDD_CORE 不过冲；
- DCDC 稳定且纹波合理；
- 复位释放晚于所有供电稳定；
- 掉电时没有 IO 反灌。

## 3. 最小系统验收

| 项目 | 通过条件 |
|---|---|
| 电源 | 所有轨在容差内，纹波可接受 |
| 时钟 | 24 MHz/32.768 kHz 起振，频率和幅值正常 |
| 复位 | SWD/按键/上电均可复位，复位源可读 |
| 调试 | 可连接、读写内存、下断点 |
| UART | VCOM/外部 UART 正常 |
| Flash | 内部 Flash 擦写和校验通过 |
| GPIO | LED/按键/测试点正常 |
| 温度 | 空载温升正常，无异常热点 |

## 4. 外设分层测试

按风险从低到高：

1. GPIO、UART；
2. 内部 Flash、DMA；
3. SPI/I2C；
4. 外部 QSPI Flash；
5. ADC/DAC/比较器；
6. PWM/编码器；
7. CAN；
8. USB；
9. Ethernet；
10. 摄像头/FlexIO/LCD；
11. 音频/触摸；
12. 双核/安全/OTA。

每个接口都要同时验证正常路径、边界条件、断开和错误恢复。

## 5. 通信一致性测试

### 串口

- 波特率误差；
- 连续数据；
- 噪声注入；
- 对端断开；
- 流控/空闲中断。

### SPI/I2C

- 时钟极性和速率；
- 总线上拉；
- 设备缺失；
- 总线拉死恢复；
- 热插拔。

### CAN

- 终端正确/缺失；
- 节点增加；
- 错误帧；
- 总线关闭恢复；
- 长线/分支。

### Ethernet

- 自协商；
- 插拔；
- DHCP；
- 丢包/延迟；
- 不同交换机/线缆；
- 与摄像头模式组合。

## 6. 模拟与电机测试

- ADC 零点、满量程、线性、串扰；
- VREF 噪声和温漂；
- 比较器阈值和迟滞；
- 运放/PGA 增益和带宽；
- PWM 死区、故障关断；
- 相序、电流方向；
- 低速、带载、堵转；
- 母线波动；
- 温升和降额。

## 7. USB 测试

- 冷启动枚举；
- 热插拔；
- Host/Device 切换；
- HS/FS 兼容；
- VBUS 压降；
- 过流；
- ESD；
- 长时间传输；
- 调试器 USB 与目标 USB 同时连接。

## 8. 低功耗测试

- 每个电源域的静态电压和电流；
- 外设逐个关闭的漏电分解；
- Deep Sleep/Power Down 进入和退出；
- RTC 唤醒；
- GPIO 唤醒；
- CAN/Ethernet/USB 唤醒；
- 调试器连接时的电流差异；
- 低电压/高温组合；
- 电池耗尽时的安全关机。

## 9. 环境与可靠性

根据产品要求安排：

- 高低温工作和存储；
- 温度循环；
- 湿热；
- 振动/跌落；
- ESD；
- EFT/浪涌；
- 辐射/传导发射；
- 电源跌落和短时中断；
- 盐雾/腐蚀（若适用）；
- 长期上电和 Flash 擦写。

## 10. 安全测试

- 错误签名/镜像；
- 回滚；
- 断电中断升级；
- 调试口认证；
- 安全/非安全越界；
- 防拆；
- 电压/时钟故障；
- 密钥销毁和恢复流程。

## 11. 量产测试建议

测试夹具至少覆盖：

- 电源轨；
- 复位/启动电流；
- 调试/编程接口；
- UART；
- Flash ID/读写；
- 时钟；
- 关键 GPIO；
- Ethernet PHY；
- CAN 收发器；
- ADC/VREF；
- 唯一 ID/安全 provisioning；
- 固件签名版本。

测试结果要绑定序列号和测试夹具版本，便于追溯。

## 12. 发布门禁

- 硬件版本和 BOM 冻结；
- 所有接口测试通过；
- 已知问题有规避方案；
- 生产编程和密钥注入可重复；
- 现场升级和恢复可验证；
- EMC/环境/安规满足目标市场；
- 数据手册和 errata 已复核到最新版本。
