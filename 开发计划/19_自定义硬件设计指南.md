# 自定义硬件设计指南

## 1. 设计策略

自制板应“参考 FRDM，不复制 FRDM”。FRDM 的目标是评估和扩展，量产板的目标是成本、可靠性、可制造性和产品合规。

建议分三板：

1. **最小系统板**：电源、复位、时钟、调试、Flash、UART、少量 IO。
2. **接口风险板**：目标产品最难的 Ethernet/CAN/USB/摄像头/模拟/电机接口。
3. **产品板**：完整 EMC、防护、隔离、结构和认证设计。

不要第一版就集齐所有功能。

## 3. 电源架构

### 3.1 最小电源树

典型外部输入可经保护与主稳压得到：

- 3.3 V 主 IO/外设电源；
- VDD_SYS 所需电压；
- VDD_CORE 由片上 DCDC 或 LDO_CORE 产生；
- VDD_ANA/VDDA；
- VDD_BAT；
- VDD_USB；
- 可选 1.8 V 或 1.2 V IO 域。

具体电源拓扑必须依据数据手册的参考连接和参考原理图。

### 3.2 上电顺序

必须满足：

- VDD_BAT 不晚于 VDD_SYS；
- VDD_CORE 在 VDD 之后；
- 未与 VDD 连接的 VDD_P2/P3/P4 在 VDD_SYS 之后；
- VDD_P4 与 VDD_ANA 同压；
- VUSB1_VBUS 与 VDD_USB 的关系按 USB 模式和参考设计处理。

多稳压器方案要做上电/掉电仿真并实测。只测稳态电压不够。

### 3.3 DCDC_CORE

- 按数据手册计算电感、输入/输出电容和反馈；
- DCDC_LX 大面积铜但控制环路面积小；
- 电感远离模拟/时钟/USB；
- 输入电容靠近 DCDC 输入；
- 输出电容靠近 VDD_CORE 引脚；
- 不允许 DCDC_LX 长距离跨层；
- 未使用 DCDC 时的 VDD_DCDC/VDD_CORE 连接必须按封装规则和手册处理。

### 3.4 去耦

- 每个电源引脚按参考设计就近放高频去耦；
- 大容量电容负责瞬态，不能替代每个引脚的小电容；
- VDD_ANA、VREFH/VREFL 需要低噪声回流；
- VDD_USB 单独滤波；
- VDD_BAT 和 RTC 保持域注意漏电；
- 电容有效值考虑 DC bias、温度和老化。

## 4. 复位

- `RESET_B` 加合适上拉/滤波；
- 保留调试器复位接口；
- 外部看门狗与 MCU 复位关系明确；
- 上电复位释放时间满足所有电源稳定；
- 复位期间 GPIO 不得驱动外部危险负载；
- 复位源可软件读取；
- 量产夹具可控制复位；
- ISP/BOOT 引脚有明确默认态和可访问焊盘。

## 5. 时钟

### 24 MHz 系统晶振

- 按晶体负载电容和 ESR 选型；
- 走线短、包地、远离 DCDC 和高速差分；
- 负载电容按实际 PCB 寄生修正；
- 预留频率测量测试点。

### 32.768 kHz RTC

- 低漏电、低噪声；
- 避免靠近高速/大电流；
- 外壳和清洗工艺影响频偏；
- 预留 RTC_CLKOUT 测试能力。

### 50 MHz Ethernet

- 有源晶振电源去耦；
- 输出串阻/匹配按参考设计；
- 到 PHY 和 MCU 的时钟走线尽量短；
- PHY strap 与时钟配置一致。

## 6. 调试和启动

最小系统至少保留：

- 10-pin SWD/JTAG；
- `RESET_B`；
- 3.3 V/GND；
- SWO（可选但推荐）；
- UART TX/RX；
- BOOT/ISP 配置焊盘；
- MCU-Link 或外部探针供电策略。

量产板可将调试口换成小间距或测试点，但不能没有受控恢复路径。

## 7. QSPI/Octal Flash

- FlexSPI 时钟和数据按目标速率做阻抗/长度控制；
- 参考板标注 50 Ω 等长；
- 每个 Flash 电源脚就近去耦；
- 片选、复位和 HOLD/WP 有明确默认；
- 不同 Flash 的命令集和 dummy cycle 不同；
- XIP 配置要和实际器件一致；
- 预留 Flash 电流测量和掉电测试点。

## 8. USB

- D+/D- 90 Ω 差分；
- 共模扼流圈和 ESD 靠近连接器；
- VBUS 检测、限流、反向保护；
- Type-C CC 逻辑和角色配置；
- 晶体/时钟与 HS PHY 要求；
- 外壳地/数字地连接策略；
- 如果做 Host，VBUS 供电能力和过流保护必须满足设备。

FRDM 只使用 HS；自定义 FS 需要重新按数据手册做引脚和 PHY 连接。

## 9. Ethernet

- RMII 50 MHz REF_CLK 稳定性；
- TX/RX 组内等长、阻抗和参考平面；
- PHY 复位和 strap 上电采样；
- MDIO/MDC 上拉；
- 变压器、Bob Smith 终端、ESD；
- RJ45 屏蔽连接策略；
- PHY 电源噪声；
- PHY 到 MCU 的 IO 电压；
- link/activity LED；
- 断链和待机功耗。

## 10. CAN

- 收发器靠近连接器；
- CAN_H/CAN_L 差分；
- 可选 120 Ω 终端和 split termination；
- 共模扼流圈；
- ESD/浪涌；
- 隔离方案按现场；
- 总线侧地/系统地设计；
- 收发器 standby/enable；
- 失效时不要阻塞总线。

开发板 CAN 连接器带 5 V，量产板是否需要向外供电要按隔离、功率和安规决定。

## 11. 模拟和电机

- VREF 低噪声、去耦、远离 DCDC；
- 模拟地与数字地分割要有依据，不能机械割地；
- 差分电流采样回流面积小；
- OpAmp/PGA 输入偏置和带宽；
- 采样电阻功率和温漂；
- PWM 与 ADC 同步；
- 比较器故障路径独立；
- 栅极驱动地与功率地/控制地关系；
- 高压/低压隔离和爬电距离。

## 12. 时钟与高速接口 PCB

FRDM 设计文件为 4 层：信号、地、电源、信号。自制板若叠层和介质不同，不能直接沿用线宽/线距。

高速设计检查：

- 完整参考平面；
- 返回电流不跨分割；
- 连接器/过孔阻抗；
- ESD 器件寄生电容；
- 晶振包地；
- DCDC 与时钟/差分隔离；
- 测试点不形成长桩；
- 去耦过孔短。

## 13. 封装与制造

MCXN947VDFT 为 0.5 mm pitch 184 VFBGA：

- 需要 BGA fanout；
- 过孔类型和焊盘尺寸按 PCB 厂能力；
- 钢网与回流曲线；
- X-ray/边界扫描/功能测试；
- 返修和烘烤流程；
- 湿热敏感等级；
- 供应封装可能不同，确认可采购型号。

## 14. EMC 与防护

- 电源入口保险丝/TVS/浪涌；
- 通信端口 ESD；
- 继电器/电机负载隔离和续流；
- DCDC 输入共模滤波；
- 晶振和高速线包地；
- 复位/BOOT 线抗扰；
- 外壳、屏蔽和接地策略；
- 预扫描后再定滤波料，避免过早堆器件。

## 15. 原理图评审清单

- [ ] 每个电源脚已连接且有去耦。
- [ ] 上电顺序满足数据手册。
- [ ] VDD_P4 = VDD_ANA。
- [ ] VDD_USB 在 3.0–3.6 V。
- [ ] 复位、BOOT、SWD、UART 可访问。
- [ ] 24 MHz/32.768 kHz/50 MHz 时钟正确。
- [ ] 所有复用引脚有网络名和用途。
- [ ] DCDC 电感参数已核算。
- [ ] QSPI/USB/Ethernet 有阻抗和回流要求。
- [ ] CAN/外部接口有 ESD 和终端。
- [ ] 模拟参考和采样链路已评审。
- [ ] DNP/替代料/封装不冲突。
- [ ] 未使用引脚按手册建议处理。

## 16. PCB 评审清单

- [ ] 叠层和阻抗已与板厂确认。
- [ ] BGA fanout 可制造。
- [ ] 电源平面完整，过孔足够。
- [ ] DCDC 回路最小。
- [ ] 时钟/差分无跨分割。
- [ ] 测试点和探测空间足够。
- [ ] 丝印有 J 编号、极性、版本和关键警告。
- [ ] 连接器机械干涉已核对。
- [ ] 装配图和 BOM 一致。
- [ ] 首件测试和返修方案明确。
