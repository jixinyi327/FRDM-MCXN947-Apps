# 排障与量产风险

## 1. 黑屏

按顺序检查：

1. 3.3 V 是否存在；
2. 背光是否点亮；
3. SW1 是否为 16 位 8080；
4. RESET 是否释放；
5. D/C、CS、WR 是否有活动；
6. 数据线上是否有波形；
7. 初始化序列是否与面板版本匹配；
8. FPC 是否偏针；
9. 转接板是否选择了错误电源路径。

如果背光不亮，问题在电源/背光；如果背光正常但黑屏，问题更可能在显示总线或初始化。

## 2. 全白、雪花或随机显示

- 8/16 位模式不匹配；
- SW1 与软件模式不一致；
- 数据总线位序错误；
- D/C 时序错误；
- WR 时钟过快；
- FlexIO shifter 配置错误；
- FPC 接触不良；
- 电源纹波或复位不稳。

先降低时钟、检查固定测试图，再替换整块屏幕交叉验证。

## 3. 颜色错误

### 红蓝互换

- RGB/BGR 配置；
- ST7796S BGR filter；
- 面板批次配置；
- 图像数据本身 BGR。

### 反色

- 面板类型需要 `invertDisplay`；
- ST7796S invert 命令；
- 白色显示成黑色、黑色显示成白色。

### 颜色阶跃/色带

- RGB565 本身色深限制；
- 渐变算法；
- 面板只支持 18-bit；
- 图像量化。

## 4. 方向错误

- 改 ST7796S orientation；
- 改 UI 资源方向；
- 改 GT911 坐标映射；
- 不要只旋转图片而保持触摸不变。

验收应覆盖显示坐标和触摸坐标同时正确。

## 5. 画面撕裂/闪烁

- 未使用 TE；
- 局部缓冲太小；
- flush 与写屏竞争；
- 双缓冲同步错误；
- 背光 PWM 频率与刷新冲突；
- 电源纹波；
- SmartDMA 与 LCD 时序冲突；
- CPU 被高优先级任务长期占用。

## 6. 触摸无响应

- GT911 地址不是 `0x5D/0x14`；
- RESET/INT 时序错误；
- 触摸 FPC 未插好；
- I2C 上拉不足或过强；
- 触摸被 LCD 复位拉低；
- INT 中断未使能；
- I2C 引脚与其他外设冲突；
- 触摸供电不足。

## 7. 触摸坐标错误

- X/Y 交换；
- X/Y 反向；
- 显示 orientation 与触摸映射不一致；
- GT911 分辨率不是 320×480；
- 坐标缩放错误；
- 边缘未校准。

## 8. 触摸误触/漂移

- 电源噪声；
- 背光调光干扰；
- 地回流差；
- I2C 上升沿慢；
- 面板与外壳压力；
- 湿手/水膜；
- 面板批次灵敏度和阈值不同；
- 触摸 FPC 屏蔽不足。

工业产品需要额外做 EFT、ESD、辐射抗扰和湿手测试。

## 9. SPI 模式速度慢

- 全屏像素量过大；
- 8-bit SPI 每次只传一字节；
- 命令/数据切换开销；
- 无 DMA；
- CPU 在 flush 中阻塞；
- 时钟不足；
- 读取操作拖慢总线；
- LVGL 进行整屏刷新。

对策：

- 用局部刷新；
- 用 DMA；
- 提升到稳定时钟；
- 用半双工写；
- 减小 UI 区域；
- 改用 8080 并口。

## 10. SmartDMA/EDMA 问题

- 芯片修订版限制；
- SmartDMA 固件地址/对齐；
- INPUTMUX 连接；
- 通道冲突；
- 缓冲区未对齐；
- 完成回调未触发；
- 同时使用摄像头/显示争用 DMA；
- cache/内存属性。

当前 SDK 代码会检查部分 MCX 芯片修订版；若从 EDMA 切到 SmartDMA，必须确认芯片修订。

## 11. 电源问题

- 同时接 J17、J11、转接板 USB 和外部 5 V；
- DC-DC 输出与 FRDM 3.3 V 顶灌；
- 背光启动导致 3.3 V 掉压；
- 背光 PWM 产生传导噪声；
- 转接板地回流不足；
- FPC 压降过大。

上电异常时先断开所有扩展电源，只保留 J17。

## 12. 量产风险

### 面板供应

- 面板原始规格较老；
- 不同批次亮度、颜色和触摸灵敏度可能不同；
- 供应商可能改 FPC/控制器；
- 需要 PCN/EOL 管理；
- 单一供应商风险高。

### 初始化一致性

- 控制器初始化序列可能依赖玻璃批次；
- 不能只按型号字符串选择驱动；
- 必须固化 RGB/BGR、invert、gamma 和方向；
- 生产固件需锁定屏幕料号。

### 光学

- 亮度分档；
- 色偏；
- 漏光；
- 坏点标准；
- 盖板贴合气泡；
- 划伤和清洁剂兼容。

### 触摸

- 传感器一致性；
- 触摸 FPC 压接；
- 电磁干扰；
- 湿手/手套；
- 长期漂移；
- 产线校准和复测。

### 机械

- FPC 弯折半径；
- 插拔次数；
- 振动磨损；
- 背光与金属结构短路；
- 屏幕受压导致 Mura；
- 转接板高度干涉。

## 13. 生产测试建议

每个产品至少测试：

- 3.3 V；
- 背光电流；
- 全部像素颜色；
- 显示方向；
- 触摸四角和中心；
- 多点触摸；
- I2C 地址；
- 固件和屏幕型号匹配；
- 背光开关；
- 低亮度闪烁；
- 复位恢复；
- 静电和接触测试（按产品要求）。

## 14. 变更控制

屏幕、触摸、FPC、控制器、背光或初始化任一变化，都应：

1. 新建硬件/BOM 版本；
2. 重新跑显示和触摸验收；
3. 重新测 RAM/帧率；
4. 重新做电源和 EMC；
5. 更新生产测试；
6. 保存样品和测试照片。
