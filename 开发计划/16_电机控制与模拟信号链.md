# 电机控制与模拟信号链

## 1. 官方参考系统

UG10251 描述了 FRDM-MCXN947 + FRDM-MC-LVPMSM 的三相 PMSM/BLDC FOC 方案。

FRDM-MC-LVPMSM：

- 输入 24–48 VDC；
- 反接保护；
- 5.5 V 辅助电源；
- 最大约 5 A RMS；
- 6 个 MOSFET + 三相栅极驱动；
- 相电流、母线电压、母线电流采样；
- 编码器/Hall 接口。

注意 UG10251 记载：市场上有一种 `VV19520XXX` 系列使用了 10 mΩ 分流和噪声较大的运放，而示例默认按原版 20 mΩ 分流调校。采购/替换扩展板必须核对版本。

## 2. 控制和 ADC 同步

官方示例使用：

| 功能 | 资源 |
|---|---|
| 三相 6 路 PWM | FlexPWM1 的子模块 0/1/2 |
| 相电流/母线采样 | ADC0，12-bit |
| PWM 触发 ADC | eFlexPWM 子模块 0 的 VAL4 触发 |
| 慢速速度环 | CTimer0 |
| 编码器 | QDC/ENC |

控制时序：

1. PWM 计数器到达指定点；
2. 触发 ADC；
3. ADC 完成中断；
4. 执行 FOC 电流环；
5. 更新 PWM。

ADC 触发点要避开开关噪声，并允许接近 100% 占空比时仍能采样。死区、PWM 频率、ADC 采样窗口必须一起优化。

## 3. 电机控制模式

UG10251 提供：

- Scalar/Voltage 控制；
- Open-loop；
- Current/torque FOC；
- Sensorless speed FOC；
- Sensored speed FOC；
- Position/servo FOC；
- MCAT 调参；
- MID 电机参数识别；
- FreeMASTER 实时观测。

推荐调试顺序：

```text
PWM/死区 -> ADC 偏置 -> 开环电压 -> 电流闭环
-> 编码器/角度 -> 速度环 -> 无感观测器 -> 位置环
```

每一步都要在低母线电压、限流和空载条件下完成。

## 4. 硬件设置

UG10251 给出：

- J22 1-2；
- J24 1-2；
- 其它跳线开路；
- 为了让过流保护工作，需要移除 R145。

这些设置与默认调试/供电场景不同。改 R145 前必须核对当前原理图和硬件版本。

扩展板接线：

1. FRDM-MC-LVPMSM 叠在 FRDM-MCXN947 上；
2. 三相电机接功率板 J7；
3. J17 接调试 USB；
4. 24 V 电源接功率板 DC 输入。

不要带电插拔功率板，不要让电机轴/线缆靠近高压。

## 5. FOC 数据链

```text
ADC 相电流/母线
-> Clarke/Park
-> 电流 PI
-> 反 Park
-> PWM 占空比
-> 功率级
-> 电机
```

传感器部分：

- 编码器/Hall 提供角度/速度；
- 无感方案用反电动势观测器；
- 电流采样需要偏置、增益和相序校准；
- 母线电压用于调制比和欠压/过压保护；
- 温度传感器用于降额/保护。

## 6. 调参内容

MCAT/MID 可识别：

- 定子电阻；
- 定子电感；
- 极对数；
- 机械参数；
- 电流环参数；
- 速度/位置环参数；
- BEMF 观测器参数。

参数识别必须在安全条件下进行，并确认：

- 转子可自由转动或按流程锁定；
- 母线限流；
- 相序；
- 编码器方向；
- 温度；
- 参数是否随温度和电流饱和变化。

## 7. 保护设计

最低保护集：

- 硬件过流/短路；
- PWM 故障输入快速关断；
- 母线过压/欠压；
- 电机堵转；
- 过温；
- 缺相；
- 编码器断线；
- 控制任务超时；
- 上电自检和故障锁存。

软件保护不能替代硬件快速关断。比较器、PWM fault 和功率级驱动关断路径应独立于普通任务调度。

## 8. 模拟信号链

开发顺序：

1. ADC 参考和偏置；
2. 通道串扰；
3. 运放/PGA 增益；
4. 采样电阻和功耗；
5. 采样时序；
6. 滤波和相位延迟；
7. 温漂和长期漂移。

使用 VREF、差分输入、SINC 和比较器时要结合噪声、带宽与安全边界选择，不能只追求分辨率。

## 9. 上电与测试

### 首次上电

1. 不接电机；
2. 用限流电源；
3. 测 5.5 V/3.3 V/栅极驱动；
4. 检查 PWM 默认全关；
5. 检查故障信号默认状态；
6. 先接假负载或小电机。

### 动态测试

- 低占空比启动；
- 正反转；
- 低速和高速；
- 逐步加载；
- 母线波动；
- 堵转；
- 温度上升；
- 断编码器；
- 断一相；
- MCU 复位。

## 10. 验收

- PWM 死区符合功率级要求；
- 故障关断延迟已测；
- 电流零点/增益校准稳定；
- 正反转和相序正确；
- 速度/位置环无持续振荡；
- 低速无失步；
- 满载温升在器件/电机范围内；
- 所有故障都能锁存、显示并安全恢复。
